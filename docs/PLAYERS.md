ULTRA GAME BOY - HOW TO PLAY
============================

Ultra Game Boy plays your Game Boy and Game Boy Color games with a
16-bit-style look: richer colours, painted skies, lighting and little
effects. Kirby's Dream Land has the fullest makeover; other games get a
general upgrade.

You need your own game files (ROMs, ending in .gb or .gbc). No games come
with the program.


GETTING STARTED
---------------

1. Unzip the download anywhere, for example to your Desktop.
2. Open the "Ultra Game Boy" folder and double-click "Ultra Game Boy.exe".
   (If Windows shows "Windows protected your PC", click "More info", then
   "Run anyway". The program isn't signed, which is why Windows asks.)
3. Click "Choose a game..." and pick your game file.
4. Play! Next time, your game is in the "Recent games" list: double-click
   it or press Enter.


CONTROLS
--------

  Arrow keys .......... move (the D-pad)
  Z ................... A button
  X ................... B button
  Enter ............... Start
  Backspace ........... Select

  Tab ................. switch between the original and the enhanced look
  E ................... turn the extra effects on or off
  Space (hold) ........ fast forward
  F2 / F4 ............. quick save / quick load
  F12 ................. take a screenshot
  Esc ................. quit


SAVES
-----

- The game's own saves work as on a real Game Boy. They're stored next to
  your game file (as "yourgame.gb.ram").
- Quick saves (F2/F4) and screenshots are kept in your user folder:
  %APPDATA%\Ultra Game Boy   (paste that into the File Explorer address bar)


GOOD TO KNOW
------------

- Kirby's Dream Land: the first time you enter an area, the program studies
  it in the background, and the screen may look plainer for a moment. After
  that it's remembered and appears straight away.
- If something goes wrong, a message tells you, and the details are saved
  in %APPDATA%\Ultra Game Boy\error.log.
